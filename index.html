Smart City Management System

A mini-project demonstrating how Data Structures can be used to manage citizens, emergencies, roads and city infrastructure.

💻 View C Source Code

Data Structures Used

👥

Linked List

Used to add and display citizens dynamically.

🚨

Queue

Used for emergency management using FIFO order.

↩️

Stack

Used to store actions and undo the most recent operation.

🛣️

Graph

Used to represent roads and connections between locations.

🌳

Tree

Used to represent City → Areas → Buildings hierarchy.

🎯 Project Objective

To demonstrate practical applications of fundamental data structures in a Smart City Management System using the C programming language.

✨ Main Features

  • Add and display citizens
  • Add and handle emergency requests
  • Add and undo previous actions
  • Add roads and display road connections
  • Display the hierarchical city structure
